## 本仓是什么

GeoLab 数学实验室。纯前端的数学可视化工作台：几何画板式的**动态几何** +
**函数图像** + **复平面** + **向量场** + MATLAB 风格的**三维曲面**，共享同一个表达式内核。
无后端、无账号、可离线，渲染全走 Canvas 2D，不依赖任何绘图库。

- 规模（实测）：前端 ts/tsx **28** 个文件；`src-tauri/src` 只有 2 个文件（Tauri 壳）
- 形态：**纯前端**
- 依赖极简：实测只有 `react` / `antd` / `typescript`（无数学库、无绘图库）

**读法**：被测的 4 个恰好是"三个最大的 + 解析器"，这**不是随机分布**，
说明作者是有意识地先罩住最重的三块。**这个取舍本身是对的。**
真正的问题在**没被测的那几个恰好是特性最独立的一批**：

- `cplane.ts`(18.6KB) 复平面 —— README 八种工作模式里**点名的一整块**
- `field.ts`(16.9KB) 向量场 —— 同样是被 README 点名的整块
- `linalg.ts`(19.0KB) 线性代数 —— 被上面几块共同依赖
- `cnum.ts`(10.5KB) 复数运算 —— 复平面与解析的地基

**也就是说：被测的是"几何/曲面/解析"，没被测的是"复数/向量场/线性代数"。**
而复数运算的错误（分支切割、模长溢出、共轭转置写反）**同样是静默的** ——
算出一个形状奇怪的图，不抛错，用户只会觉得"这功能有点怪"。

## P0 —— 给 `cnum.ts` 与 `linalg.ts` 建网（它们是地基）

- **P0-1 `cnum.ts`（10.5KB）**：复数运算。纯函数、极易测、且被多处依赖。
  可测点：模/辐角、`pow` 的整数/分数次幂、共轭转置、除法的数值稳定性。
- **P0-2 `linalg.ts`（19.0KB）**：被 `cplane` / `field` / 曲面共同依赖的地基。
  可测点：矩阵乘结合律、逆矩阵往返、奇异矩阵的行为（**要断言它报错或给
  可识别结果，不能静默返回 NaN**）。
- **P0-3 `cplane.ts` + `field.ts`**：这两块是 README 点名的特性。
  先测它们内部可分离的纯计算部分（映射公式本身），画布部分另说。
